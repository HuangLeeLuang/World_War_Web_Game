# 霓虹霸權

單機瀏覽器戰略遊戲原型。主題是近未來企業軍閥與城市群戰爭，玩法核心包含多城市地圖、人物四能力、氣候與地形修正、軍事衝突、黑市行動、奢侈品與戰略資產。

## 開啟方式

直接用瀏覽器開啟：

```text
D:\CodeX\Game\index.html
```

目前不需要安裝套件或啟動伺服器。

其他頁面：

- `D:\CodeX\Game\guide.html`：攻略。
- `D:\CodeX\Game\modifier.html`：修改器，可調整回合、勢力資源、城市數值、人物能力。

## 目前已做內容

- 8 座代表城市，包含海岸都市、沙漠、山岳、極寒工業、熱帶港口、海島堡壘與高密度都市。
- 5 個勢力，玩家控制「黑曜聯盟」。
- 8 名初始人物，男女各半，且每名初始人物都有肖像。
- 人物能力簡化為：指揮、謀略、經營、魅力。
- 可建立自訂人物並上傳頭像，資料存在瀏覽器本機。
- 內建 AI 生成城市縮圖、人物肖像與物品類別圖。
- 城市天候會每回合變化，並影響進攻效率。
- 可以徵兵、強化防禦、投資產業、進攻相鄰敵方城市。
- 奢侈品與資產是永久持有物，不是隨機抽卡。
- 行動牌只代表本回合戰術行動，不取代物品與資產。
- 支援本機儲存與讀取。
- 主頁提供攻略與修改器連結。

## 修改器使用方式

1. 在遊戲主頁按「儲存」，或直接到修改器按「建立初始存檔」。
2. 到 `modifier.html` 調整數值。
3. 按「套用並儲存」。
4. 回到遊戲主頁按「讀取」，或重新整理頁面。

## 物品系統方向

物品分為四類：

- 個人物品：西裝、名錶、義體等，裝備到人物身上。
- 載具：超跑、防彈車隊、直升機、私人飛機等。
- 生活資產：豪宅、夜店、私人俱樂部等。
- 戰略產業：安保公司、軍事情報公司、軍火製造商、上市控股公司等。

## 視覺素材

目前第一批專案素材在：

- `assets/cities/`：8 張城市縮圖。
- `assets/officers/`：8 張初始人物肖像。
- `assets/items/`：4 張物品類別縮圖。
- `assets/city-background.png`：主背景圖。

這些圖使用內建 imagegen 產生，設定為原創近未來寫實風，避免文字、品牌與既有遊戲 IP。
